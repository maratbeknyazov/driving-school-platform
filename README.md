# Apex Drive

Статический тренажёр ПДД с текущим банком из 1 351 вопроса в 68 блоках, 800 иллюстрациями, тренировкой и пробным экзаменом. Есть переключение RU/EN для интерфейса и RU / узбекская латиница / узбекская кириллица для вопросов.

## Запуск

В этой папке выполните команду с Python 3 и откройте `http://127.0.0.1:4174/`.

```bash
python -m http.server 4174 --bind 127.0.0.1
```

Браузер загружает HTML, CSS и ES-модули напрямую. Сборка и установка пакетов отсутствуют. Three.js 0.160.1 и GSAP 3.12.5 загружаются с jsDelivr. Space Grotesk и IBM Plex Mono загружаются с Google Fonts. Текстовый список деталей доступен при отключённой 3D-сцене.

## Структура

- `js/data/bank.js` хранит исходный банк и его ID. Иллюстрации лежат в `assets/media/`.
- `js/data/categories.js` содержит категории и параметры пробной сессии, а `js/data/vehicle.js` содержит материалы по узлам автомобиля.
- `js/main.js` связывает вопросы, пробный экзамен, список деталей и настройки языка с интерфейсом.
- `js/scene.js` содержит интерактивную модель и сцену первого экрана.
- `js/tracker.js` хранит попытки и статистику под ключом `apex.progress.v1`.

Интерфейс, экзамен с таймером, тренировка, прогресс и 3D-разбор собраны. Билеты и тренировка используют только вопросы с непустым разбором — сейчас это 966 из 1 351; остальные остаются в банке и статистике, но не попадают в попытку без объяснения. Проверки: `node tests/progress.mjs` (XP, бонусы, уровни) и `node ../_archive_mobile_apk/tools/verify.mjs` (данные и ссылки). При переразбиении банка сохраняйте ID вопросов для совместимости с прогрессом.
